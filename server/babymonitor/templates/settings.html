Android
  1. Install ntfy from Google Play or F-Droid.
  2. Download the certificate above. In ntfy's settings, find the certificates section and add the downloaded file (newer app versions only).
  3. In ntfy's settings, under users, add the server, user and password above.
  4. Tap + and subscribe to the topic above, choosing "use another server" with the server above.
  5. For a loud alarm: open the subscription's notification settings and allow it to override Do Not Disturb.
iPhone
  1. Open this page in Safari and download the certificate above. Settings → Profile Downloaded → Install. Then Settings → General → About → Certificate Trust Settings → turn on full trust for it.
  2. Install ntfy from the App Store. In ntfy: Settings → Default server → the server above, exactly. Then add the user and password in its users section.
  3. Tap + → topic above → Subscribe.
  4. iPhones are woken through ntfy.sh, so the monitor needs internet: no phone alerts on iPhone while the monitor runs its own hotspot.

Wi-Fi

    The monitor leaves its current network to join this one. If this page was opened through the monitor's hotspot, connect this phone to the same network, then open the monitor again (by name, or the address your router shows). If joining fails, the monitor returns to its hotspot.

      Hotspot
